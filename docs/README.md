# 制作を再開する

## シーンを選ぶ

[対応表CSV](scene-map.csv)に、共有対象の5シーンと対応するBlenderを記載しています。採用・保存動画は8本あり、そのうち4本にBlender動画を実際に入力しています。残る4本は画像入力で生成しており、別のBlenderを推測して割り当てません。

目覚ましはBlenderのV17Bだけが明示採用されています。実写動画はまだありません。未採用のV19B2準備データ、眠る母の準備版、旧版や初期試作は今回の共有物に含めません。

## 選ぶシーン

.blendを開いたら、画面上部のScene欄を[入口の表](../README.md)に合わせます。過去の川岸は `V47_V42_IMMEDIATE_STEP` を選ぶと、実際の生成に使った配置・動きが表示されます。

## 配置と動きを見る

Outlinerで物体を選び、NキーのTransformで位置・回転・大きさを確認します。カメラには親のEmptyやConstraintsで動くものもあるため、カメラ本体だけでなくタイムラインを再生して確認します。物体の簡易形状は動きや配置の目印で、完成した実写の外見は入力画像と完成動画で確認します。

## 制作に使ったプロンプト

`prompts/`に、Blender動画を実際に入力した4本の生成プロンプトを収録しています。入力画像と動き参照はDriveの制作資料で、同じシーン名から確認できます。プロンプトの閲覧で生成サービスへの送信は行われません。

## ファイル構成

- `blender/scenes/`：選んだBlender5ファイル。
- `blender/metadata/`：それぞれのカメラ・配置・動きと照合結果。
- `docs/scene-map.csv`：採用Blender5シーンとの対応。
- `prompts/`：Blender入力を使った4本の生成プロンプト。
- `verification.json`：共有コピーをこのPCで開き直した検証結果。

構築コードの全履歴や一括再生成スクリプトは配布しません。制作済みの.blendを編集元として開き、次の構図や動きを作ります。
